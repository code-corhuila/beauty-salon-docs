## Notas de versión

**Para la manicurista y sus clientas (app):**
- La clienta puede ver los servicios, crear su cuenta, agendar una cita en un cupo libre, ver sus
  citas y cancelarlas.
- El negocio puede registrar a sus profesionales, crear, editar y pausar servicios con su horario, y
  ver y responder las citas de su agenda.
- El catálogo se ve aunque no haya señal, con un aviso de cuándo se guardó.

**Para el equipo (API):**
- Ver el GitHub Release `v1.0.0` de `beauty-salon-api`.

## Go / No-Go

### Code & tests
- [ ] All target stories meet the [Definition of Done](../../00-governance/definition-of-done.md).
      — Las HU-08 a HU-19 tienen código, pruebas y están en `main`. ⚠️ Los PR se unieron **sin la
      aprobación** de la otra integrante en GitHub, que la DoD y ADR-018 piden
- [x] Unit + widget + integration suites green.
      — App: 215/215 en Vitest y 4/4 E2E en Cypress (2026-11-09). API: 19 pruebas de `node:test`,
      13/13 en Postman y 67 sondas de smoke test (2026-11-08). Detalle en
      [`testing-strategy.md`](../../04-quality/testing-strategy.md)
- [x] No open critical/blocker defects. — TC-001 a TC-010 ejecutados el 2026-11-08. Los defectos que salieron
      en el emulador (D-A y D-C) se corrigieron y se volvieron a probar (app PR #28)

### Quality gates
- [ ] Startup time within budget (vs. previous release). — ⏳ sin medir (P-02)
- [ ] App size within budget (increase justified). — ⏳ sin medir para esta versión
- [x] [Mobile security checklist](../../04-quality/mobile-security.md) passed.
      — Los cuatro bloqueos de v0.1.0 están resueltos (app PR #21): `appId`
      `co.edu.corhuila.manicita`, `allowBackup="false"`, `minifyEnabled true` y sin `console` ni
      `debugger` en el JavaScript de release. Pendiente: la API sin HTTPS (H-01)

### Build & signing
- [ ] Built from CI on `main` at tag `v1.0.0`. — ⏳ no hay CI de la app (R-02, R-03); el Release de la
      API se creó a mano porque `release.yml` termina en `startup_failure`
- [ ] Signed with the correct release identity. — ⏳ sin llave de release (S-01); el APK de la demo es
      de depuración

      `0.0.1`, el de la API `0.1.0`, y Android sigue en `versionName "1.0"` / `versionCode 1` (debería
      ser `10000`). Deuda S-03

### Store

### Observability
